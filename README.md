# Cuff

Cuff is a screenless wearable fitness tracker and identity token. It is extremely lightweight and slips into crochet bands (or any fiber/fabric bands) of your making. Despite its size, it fully features health tracking (steps/activity, HR/SpO2, sleep), and a FIDO2 security key with NFC + BLE. 

Cuff is a piece of tech designed to integrate with fashion. To integrate functionality without getting in the way. While being beautiful.
